# Online-TimeTable-Genrerator

## Live Demo: https://online-time-table-genrerator.vercel.app/

A simple web-based application that allows users to generate class timetables instantly by entering subjects, teachers, classes, working days, and number of periods.

## 🚀 Features

- Enter multiple classes, subjects, and teachers
- Automatically generates timetable
- Displays timetable in clean table format
- Download timetable as PDF
- Fully responsive UI
- Easy to use (no login required)

## Tech Stack

- HTML
- CSS
- JavaScript
- html2canvas
- jsPDF

## 📌 How to Use

1. Enter class names (comma separated)
2. Enter subject names
3. Enter teacher names
4. Enter working days
5. Enter periods per day
6. Click **Generate Timetable**
7. Click **Download PDF** to save it
